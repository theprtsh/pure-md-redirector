# Pure.md Redirector - Firefox Extension

A simple Firefox extension that opens the current tab's URL in [pure.md](https://pure.md) for clean, distraction-free reading.

## Features

- Click extension icon to open current page in pure.md
- Customizable keyboard shortcut (default: `Ctrl+Shift+F`)
- Dark Gruvbox theme settings page
- Real-time shortcut display

## Installation

1. Download/clone this repository
2. Open `about:debugging` in Firefox
3. Click "This Firefox" → "Load Temporary Add-on"
4. Select `manifest.json`

## Usage

- **Click** the extension icon in toolbar
- **Press** keyboard shortcut (customize in `about:addons` → Manage Extension Shortcuts)

## Files

- `manifest.json` - Extension configuration
- `background.js` - Main functionality
- `options.html` - Settings page

## Disclaimer

This extension is not affiliated with or endorsed by pure.md. It simply provides a convenient way to open URLs in their service.
