Pure.md Redirector Settings

Keyboard Shortcut
Default shortcut: Ctrl+Shift+F
To change the keyboard shortcut:
1. Go to about:addons in Firefox
2. Click the gear icon and select "Manage Extension Shortcuts"
3. Find "Pure.md Redirector" and set your preferred shortcut

How to Use

1. Click the extension icon in the toolbar to open the current page in Pure.md
2. Use the keyboard shortcut (default: Ctrl+Shift+P) to quickly open in Pure.md
3. Pure.md will open the current tab's URL in a new tab
